## 1. 서비스가 필요한 이유

### 사용자

- 경북 소프트웨어 마이스터고등학교 학생들
- 한계: 첫 버전은 학생인지 확인하지 않고 누구나 가입할 수 있습니다. 실제 학교에서 운영할 때는 학교 이메일로 가입을 제한하거나 이메일 인증을 검토합니다.

### 문제

**1. 문제 정의**

기숙사 생활을 하는 저희 학교의 특성상 분실물이 발생하는 장소가 한정되어 있음에도 불구하고, 분실물 정보가 한곳에 모이지 않고 각자 채팅방에 개별적으로 공유하고 있어 필요한 정보를 찾기 어렵습니다.

**2. 기존 시스템의 한계**

현재 - 분실물 사진과 정보를 각 반 단체 채팅방에 올리는 방식

문제점 :

- 확인이 늦음 : 분실물 안내가 채팅에 묻힘.
- 검색이 불편함 : 종류·색상·장소별 검색이 어려움.
- 관리가 어려움 : 찾아간 물건의 안내가 남아 있음.

**3. 그로 인한 피해**

학생들은 자신의 물건이 발견되었는지 확인하기 위해 여러 채팅방을 살펴보거나 주변에 일일이 물어봐야 합니다. 분실물 정보를 제때 확인하지 못하면 물건을 찾는 데 시간이 오래 걸리고, 결국 물건을 되찾지 못할 수도 있습니다. 또한 담당자는 같은 정보를 여러 채팅방에 반복해서 올려야 해 번거롭습니다.

이처럼 분실물 공유가 비효율적으로 이루어지면 학생들의 불편이 커지고, 학교 안에서 분실물을 체계적으로 관리하기 어려워집니다.

### 해결방안

분실물과 습득물 정보를 한곳에 모아 관리하는 웹 서비스 찾Go를 개발합니다.

- 한곳에 등록 : 분실물과 습득물을 사진과 함께 한 번만 올리면 모든 학생이 볼 수 있습니다. → 확인 지연 해결
- 검색과 분류배치 : 분실/습득으로 구분하여 배치 하고, 상품명과 위치를 통해 검색하여 원하는 물건을 바로 찾을 수 있습니다. → 검색 불편 해결
- 상태 관리 : 주인을 찾으면 '해결 완료' 상태로 바꿔 목록을 최신으로 유지하고, 내가 올린 글은 마이페이지에서 관리할 수 있습니다. → 관리 어려움 해결

### 기대효과

- 학생들은 여러 채팅방을 확인하지 않아도 한곳에서 빠르게 물건을 찾을 수 있습니다.
- 담당자는 한 번만 등록하면 되므로 반복 작업이 줄어듭니다.
- 분실물 기록이 쌓이면 학교 안에서 분실물을 체계적으로 관리할 수 있습니다.

## 2. 첫 버전의 목표

습득자가 분실물을 발견하면 보관 장소에 맡기고, 맡긴 보관 장소를 적어 습득물로 등록합니다. → 분실자는 로그인 없이 습득물 목록에서 잃어버린 물건의 정보로 검색해 자기 물건을 찾고, 보관 장소에서 돌려받거나, 게시물에 표시된 작성자에게 연락해 돌려받습니다. → 물건이 전달되면 게시물 작성자가 상태를 '해결 완료'로 바꿉니다.

- **작성자 연락처**는 작성자가 회원가입 때 입력한 전화번호입니다. 로그인한 사용자에게만 보이고, 전화번호를 입력하지 않은 작성자는 연락처를 표시하지 않습니다.
- 연락처를 공개하지 않고 서비스 안에서 대화하는 기능(채팅)은 후속 기능으로 둡니다.
- 물건을 돌려받는 과정은 아래 세 단계로 나눕니다. 서비스가 기록하는 것은 마지막 '해결 완료' 하나입니다. 프론트엔드·백엔드·DB의 세부 담당은 「기능 동작과 예외 상황」 문서에 정리합니다.

| 단계 | 하는 일 | 누가, 어디서 |
| --- | --- | --- |
| 소유 확인 | 찾으러 온 학생이 실제 주인인지 확인합니다. | 보관 장소에서 직접 확인하거나, 작성자에게 연락해 물건의 특징을 확인 (서비스 밖) |
| 물건 전달 | 확인된 주인에게 물건을 넘겨줍니다. | 보관 장소에서 받아 가거나, 작성자와 약속해서 받음 (서비스 밖) |
| 해결 완료 | 게시물 상태를 '해결 완료(RESOLVED)'로 바꿔 다른 학생이 더 찾지 않게 합니다. | 게시물 작성자가 서비스의 수정 화면에서 변경 |

- 같은 물건에 분실물 글과 습득물 글이 따로 올라와도 첫 버전에서는 서로 연결하지 않습니다. 물건이 돌아간 뒤 두 글의 작성자가 각자 '해결 완료'로 바꿉니다.

### MVP

**1. 회원가입**

이메일, 비밀번호, 이름을 등록해 회원가입한다. 전화번호는 원하는 사람만 입력한다. 입력한 전화번호는 내가 올린 게시물의 작성자 연락처로, 로그인한 사용자에게만 보인다. 입력하지 않으면 화면에 표시하지 않는다.

- 입력 : (필수) 이메일, 비밀번호(8~64자), 비밀번호 확인, 이름(40자 이하) / (선택) 전화번호(010-0000-0000 형식)
- 동작 : 입력 형식이 맞으면 회원 정보를 저장하고 "회원가입이 완료되었습니다. 로그인해주세요."를 표시한 뒤, 이메일이 채워진 로그인 화면으로 이동한다. 자동으로 로그인하지 않는다.
- 예외 :
  - 미입력 : "이름을 입력해주세요."
  - 이메일 형식 오류 : "이메일 형식이 올바르지 않습니다."
  - 이메일 중복 : "이미 가입된 이메일입니다. 로그인해주세요."
  - 비밀번호 길이 오류 : "비밀번호는 8~64자로 입력해주세요."
  - 비밀번호 확인 불일치 : "비밀번호가 일치하지 않습니다."
  - 전화번호 형식 오류 : "전화번호 형식을 확인해 주세요."

**2. 로그인 / 로그아웃**

이메일과 비밀번호로 로그인하고, 이용이 끝나면 로그아웃한다. 로그인은 물품 등록·관리, 마이페이지처럼 회원 기능을 쓸 때만 필요하다.

- 입력 : 이메일, 비밀번호
- 동작 : 정보가 맞으면 서버가 JWT 토큰(accessToken)과 사용자 정보(id, 이름, 이메일)를 발급하고, 화면은 이를 브라우저에 저장해 로그인 상태를 유지한다. 로그인이 필요한 요청에는 이 토큰을 함께 보낸다. 로그인 후에는 원래 하려던 화면으로 이동하고, 없으면 마이페이지로 이동한다. 로그아웃하면 서버에 요청하지 않고 저장된 토큰과 사용자 정보를 삭제한 뒤 물품 목록(첫 화면)으로 이동한다.
- 예외 :
  - 정보 불일치 : "이메일 또는 비밀번호가 올바르지 않습니다. 다시 입력해주세요."
  - 로그인 필요 : "로그인이 필요한 기능입니다."
  - 토큰 만료 : "로그인이 만료되었습니다. 다시 로그인해주세요."

**3. 물품 등록**

분실하거나 습득한 물건의 사진과 정보를 등록한다.

- 입력 : (필수) 구분(분실물/습득물), 물품 이름, 설명, 분실·습득 장소, 분실·습득 날짜, 보관 장소(습득물만) / (선택) 사진 1장
- 동작 : 사진을 먼저 업로드한 뒤 정보를 입력하고, '찾는 중(OPEN)' 상태로 게시물을 저장한다. 작성자는 로그인한 사용자로 지정한다. 저장되면 등록한 물품의 상세 화면으로 이동한다.
  - 보관 장소 칸은 습득물 등록 화면에서만 보이고 반드시 입력해야 한다. 분실물 등록 화면에는 칸을 표시하지 않고 값을 보내지 않는다. 칸 표시는 프론트엔드가, 습득물의 필수 검사는 프론트엔드와 백엔드가 함께 한다.
  - 사진을 올린 뒤 글을 등록하지 않고 끝내면, 글에 연결되지 않은 사진은 3시간 뒤 자동으로 삭제한다.
- 예외 :
  - 미입력 : "OO을 입력해주세요."
  - 글자 수 초과 : "이름·장소는 100자, 설명은 2000자 이하로 입력하세요."
  - 미래 날짜 : 오늘 이후 날짜는 고를 수 없다.
  - 사진 형식·용량 오류 : "JPG/PNG, 5MB 이하 사진만 올릴 수 있습니다. 다른 사진을 선택해주세요."
  - 사진 처리 실패 : "사진을 처리하지 못했습니다. 다른 사진을 선택해주세요."
  - 로그인 필요 : "로그인이 필요한 기능입니다."

**4. 물품 목록 조회**

등록된 물품을 조회한다. 서비스에 접속하면 처음 보이는 화면이며, 로그인 없이 볼 수 있다.

- 목록 분류 : 분실물 / 습득물
- 동작 : 분실물과 습득물로 나누어 보여 주고, 등록 일시(createdAt) 최신순으로 20개씩 표시한다. 목록 맨 아래의 "더 보기" 버튼으로 다음 20개를 이어 붙인다.
- 날짜 기준 : 목록 정렬에 쓰는 날짜는 등록 일시(createdAt)다. 분실·습득 날짜(lostFoundAt)는 물건을 잃어버리거나 주운 날로, 화면에 표시만 하고 정렬에는 쓰지 않는다. 아직 해결되지 않은 물품만 보려면 상태 필터를 쓴다.
- 예외 :
  - 결과 없음 : "아직 등록된 물품이 없습니다. 첫 물품을 등록해 보세요."

**5. 물품 상세 조회**

사진과 정보를 확인해 내 물건이 맞는지 판단한다.

- 입력 : 목록에서 물품 선택
- 동작 : 사진, 이름, 설명, 분실·습득 장소, 보관 장소(습득물만), 날짜, 상태, 작성자 이름, 작성자 연락처(로그인한 사용자만)를 표시한다. 로그인한 사용자가 작성자면 "수정"·"삭제" 버튼을 표시한다.
  - 값이 없는 선택 항목(보관 장소, 작성자 연락처)은 칸 자체를 표시하지 않는다. 사진만 예외로, 없으면 기본 이미지를 보여 준다.
  - 비회원에게는 연락처 자리에 "로그인하면 작성자 연락처를 볼 수 있습니다."를 표시한다.
- 예외 :
  - 물품 없음 : "해당 물품을 찾을 수 없습니다. 삭제되었거나 주소가 잘못되었을 수 있습니다."

**6. 물품 검색**

검색어와 조건을 골라 원하는 물품을 찾는다.

- 입력 : (선택) 검색어(100자 이하), 구분(분실물/습득물), 상태(찾는 중/해결 완료), 정렬(최신순/오래된 순, 등록 일시 기준)
- 동작 : 앞뒤 공백을 지운 검색어가 물품 이름, 설명, 장소, 보관 장소 중 하나에 들어 있는 물품을 찾고, 고른 조건을 함께 적용해 20개씩 표시한다. 검색 조건은 주소에 담아 뒤로 가기와 새로고침에도 유지한다. 로그인 없이 이용할 수 있다.
- 예외 :
  - 검색어 초과 : "검색어는 100자 이하로 입력하세요."
  - 결과 없음 : "검색 결과가 없습니다. 다른 검색어로 찾아보거나 분실물로 등록해 두세요."

**7. 마이페이지**

내 정보와 내가 등록한 물품을 모아 보고 관리한다.

- 입력 : 마이페이지 진입
- 조회 : 전체 조회, 구분·상태에 따라 조회
- 동작 : 내 정보, 등록한 습득물·분실물 개수, 내가 등록한 물품 목록을 표시한다. 각 물품에서 수정·삭제로 이동한다.
- 예외 :
  - 로그인 필요 : "로그인이 필요한 기능입니다."
  - 등록한 물품 없음 : "아직 등록한 물품이 없습니다."

**8. 물품 관리 (수정·삭제·상태 변경)**

작성자가 등록한 물품의 정보를 고치거나 삭제하고, 물건이 주인에게 전달되면 상태를 바꾼다.

- 입력 : 수정할 정보 / 삭제 버튼 / 상태 선택(찾는 중 ↔ 해결 완료)
- 동작 :
  - 수정 : 화면의 모든 항목을 한 번에 저장한다. 선택 항목을 비우고 저장하면 기존 값도 지워진다. 저장되면 상세 화면에 바뀐 내용을 표시한다.
  - 상태 변경 : 물건이 주인에게 전달된 뒤, 작성자가 수정 화면에서 상태를 '해결 완료(RESOLVED)'로 바꿔 저장해 목록에서 구분한다. 소유 확인과 물건 전달은 서비스 밖(보관 장소, 또는 작성자와 연락)에서 이루어진다.
  - 삭제 : 확인창에서 "확인"을 누르면 삭제하고 "삭제되었습니다."를 표시한 뒤 마이페이지로 이동한다.
- 예외 :
  - 작성자가 아님 : "본인이 등록한 물품만 수정·삭제할 수 있습니다."
  - 로그인 필요 : "로그인이 필요한 기능입니다."
  - 삭제 확인 : "정말 삭제하시겠습니까? 삭제하면 되돌릴 수 없습니다."
  - 수정 시 입력 오류 : 물품 등록과 같은 메시지

### 추가 기능 (후속)

- 채팅 기능
  - 입력: 습득자 또는 분실자 선택
  - 동작: 습득자와 분실자가 물품 관련 정보를 주고받는다.
  - 첫 버전에서는 보관 장소나 작성자 연락처(전화번호)로 물건을 돌려받고, 연락처를 공개하지 않는 대화는 이 기능에서 다룬다.
- 유사도 분석
  - 입력: 물품 사진 및 정보 등록
  - 동작: 이미지와 입력 정보를 분석하여 기존 등록 물품 중 유사한 물품을 찾아 표시한다.
- 물품 종류 선택·필터
  - 입력: 물품 종류(전자기기, 지갑/카드, 의류, 가방, 필기구, 기타)
  - 동작: 등록할 때 종류를 고르고, 목록에서 종류별로 걸러 본다.
  - 첫 버전에서는 제외하고 검색어로 찾는다.

## 3. 성공 기준

찾Go 서비스를 통해 사용자가 습득물과 분실물을 등록하고, 물품을 확인하여 잃어버린 물건을 찾을 수 있는지를 기준으로 합니다.

- 회원가입 및 로그인: 사용자가 계정을 생성하고 로그인하여 서비스를 이용할 수 있다.
- 마이페이지: 사용자가 자신의 회원 정보와 등록한 물품을 확인하고 수정 및 삭제할 수 있다.
- 물품 등록: 사용자가 분실물 또는 습득물을 사진과 정보로 등록할 수 있다.
- 물품 검색: 사용자가 등록된 물품을 물품명과 위치를 통해 검색하여 원하는 물품을 찾을 수 있다.
- 물품 확인: 사용자가 물품의 사진과 상세 정보를 확인하여 자신의 물건인지 판단하고, 보관 장소나 작성자 연락처로 물건을 돌려받을 수 있다.

> **핵심:** 좋은 아이디어라는 평가보다, 사용자가 실제로 목적을 이룰 수 있는지가 중요합니다.
