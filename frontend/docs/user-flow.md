# 사용자 이용 흐름

> **📖 작성 가이드**
>
> **이 문서의 목적**
>
> 사용자가 서비스를 처음 열어 목적을 달성할 때까지의 순서와, 중간에 막혔을 때의 경로를 정리합니다.
>
> **1. 큰 흐름부터 정리하기**
>
> 사용자 흐름은 화면 목록이 아니라 사용자가 목적을 이루는 과정입니다. 시작점, 핵심 행동, 결과 확인, 다음 행동을 순서대로 작성합니다.
>
> 처음에는 각 단계의 이름만 연결하고, 이후 단계마다 필요한 화면과 조건을 덧붙입니다. 이때 사용자가 왜 다음 단계로 이동하는지 설명할 수 있어야 합니다.
>
> **2. 단계별로 확인할 내용**
>
> - 사용자 행동: 입력, 선택, 이동 중 무엇을 합니까?
> - 서비스 반응: 로딩, 안내, 결과 중 무엇을 보여줍니까?
> - 다음 조건: 어떤 상태가 되어야 다음 단계로 갈 수 있습니까?
> - 종료 상태: 사용자는 목적 달성을 어떻게 확인합니까?
>
> 이 네 가지가 빠지면 화면은 있어도 실제 이용 경로가 끊길 수 있습니다.
>
> **3. 갈림길과 되돌아가는 경로**
>
> 정상 흐름만 정리하지 않습니다. 취소, 뒤로 가기, 빈 결과, 입력 오류, 연결 실패가 발생했을 때 사용자가 어디에서 다시 시작하는지 표시합니다.
>
> **핵심:** 오류가 생겨도 사용자가 현재 위치와 다음 행동을 알 수 있어야 합니다.

## 이 문서의 목적

찾Go는 학교 안에서 잃어버린 물건과 주운 물건을 한곳에 모으는 서비스입니다. 물건을 잃어버린 사람은 누군가 주워서 등록했는지 찾아보고, 물건을 주운 사람은 그 물건과 보관 장소를 알립니다.

이 문서는 사용자가 찾Go에 처음 접속해서 물건을 찾거나 등록하고, 그 결과를 확인할 때까지의 흐름을 정의합니다. 중간에 막혔을 때 어디로 돌아가서 다시 시작하는지도 함께 정합니다.

### 사용자와 목적

| 사용자 | 목적 | 로그인 |
| --- | --- | --- |
| 물건을 잃어버린 사람 | 누가 주워서 등록했는지 찾아보고, 보관 장소에서 돌려받거나 작성자에게 연락해 돌려받습니다. 없으면 분실물로 등록해 둡니다. | 찾기는 필요 없음, 작성자 연락처 보기와 등록은 필요 |
| 물건을 주운 사람 | 주운 물건을 보관 장소에 맡기고, 물건과 보관 장소를 습득물로 등록해 알립니다. | 필요 |
| 물품을 등록한 사람 | 내가 등록한 물품을 확인하고 수정·삭제하며, 물건이 전달되면 '해결 완료'로 바꿉니다. | 필요 |

### 화면 구성

| 화면 | 역할 | 로그인 필요 |
| --- | --- | --- |
| 물품 목록 | 서비스의 첫 화면입니다. 분실물과 습득물을 모아 보고 검색합니다. | 아니요 |
| 물품 상세 | 물건의 특징, 장소, 날짜, 보관 장소, 작성자 연락처를 확인합니다. | 아니요 (작성자 연락처는 로그인한 사용자만) |
| 로그인 | 회원 기능의 입구입니다. 헤더의 "로그인"을 누르거나, 로그인이 필요한 기능을 쓸 때 이동합니다. | 아니요 |
| 회원가입 | 이메일, 이름, 비밀번호(필수)와 전화번호(선택)로 계정을 만듭니다. | 아니요 |
| 물품 등록 | 습득물 또는 분실물을 등록합니다. | 예 |
| 물품 수정 | 내가 등록한 물품의 내용과 상태(찾는 중/해결 완료)를 고칩니다. | 예 (본인 물품) |
| 마이페이지 | 내 정보와 내가 등록한 물품을 확인합니다. | 예 |

모든 화면 위쪽에는 헤더를 둡니다. 헤더에는 "찾Go" 로고, "습득/분실물 조회", 로그인 상태("로그인" 또는 "OOO님"), "로그아웃" 버튼이 있습니다. 사용자는 어느 화면에서든 헤더로 목록이나 마이페이지에 돌아갈 수 있습니다.

## 1. 큰 흐름

### 목적별 흐름

| 흐름 | 단계 |
| --- | --- |
| A. 물건 찾기 | 첫 접속(물품 목록) → 검색 → 물품 상세 → 보관 장소에서 받거나 작성자에게 연락해 받기 |
| B. 회원 되기 | 헤더의 "로그인" 또는 로그인이 필요한 기능 → 로그인 화면 → 회원가입 → 로그인 → 원래 하려던 화면 또는 마이페이지 |
| C. 물건 등록하기 | 물품 목록 → 등록하기 → (로그인) → 정보 입력 → 등록 완료 → 마이페이지에서 확인 |
| D. 내 물품 관리 | 마이페이지 → 내 물품 상세 → 수정 또는 삭제 → 결과 확인 |
| E. 돌려받기와 해결 완료 | 소유 확인(보관 장소 또는 작성자와 연락) → 물건 전달 → 작성자가 상태를 '해결 완료'로 변경 → 목록·상세에 표시 |
| F. 이용 마치기 | 로그아웃 → 물품 목록(첫 화면) |

### 전체 순서

**접속(물품 목록) → 물품 조회·검색 → 물품 상세 → (등록할 때) 로그인 또는 회원가입 → 물품 등록 → 결과 확인 → 관리·해결 완료 → 로그아웃**

| 순서 | 단계 | 화면 | 다음 단계로 가는 이유 |
| --- | --- | --- | --- |
| 1 | 접속 | 물품 목록 | 첫 화면은 물품 목록입니다. 로그인하지 않아도 등록된 물건을 바로 보고 검색할 수 있습니다. |
| 2 | 물품 조회·검색 | 물품 목록 | 등록된 물건 중 내 물건이 있는지 찾습니다. 비슷한 물건을 누르면 상세 화면으로 갑니다. |
| 3 | 물품 상세 | 물품 상세 | 장소, 날짜, 특징을 보고 내 물건인지 판단합니다. 내 물건이면 보관 장소로 찾으러 가거나, 로그인해서 작성자 연락처로 연락합니다. |
| 4 | 로그인·회원가입 | 로그인, 회원가입 | 찾는 물건이 없어 분실물로 등록하거나, 주운 물건을 습득물로 등록하려면 로그인해야 합니다. 계정이 없으면 회원가입한 뒤, 이메일이 채워진 로그인 화면에서 로그인합니다. 로그인하면 원래 하려던 화면으로 돌아갑니다. |
| 5 | 물품 등록 | 물품 등록 | 찾는 물건이 없으면 분실물로, 물건을 주웠으면 습득물로 등록합니다. |
| 6 | 결과 확인 | 물품 상세, 마이페이지 | 등록하면 바로 등록한 물품의 상세 화면이 열리고, 마이페이지 목록에도 추가됩니다. |
| 7 | 관리·해결 완료 | 마이페이지, 물품 수정 | 내 물품을 고치거나 지우고, 물건이 주인에게 전달되면 상태를 '해결 완료'로 바꿉니다. |
| 8 | 로그아웃 | 물품 목록 | 이용을 마치면 로그아웃하고 첫 화면인 물품 목록으로 돌아갑니다. |

## 2. 단계별 흐름

각 흐름은 사용자 행동, 서비스 반응, 다음 조건을 순서대로 적고, 마지막에 종료 상태를 적습니다.

### 2-1. 처음 접속과 물건 찾기 (목록·검색·상세)

로그인하지 않아도 이용할 수 있습니다.

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 서비스 주소로 접속하거나, 헤더의 "습득/분실물 조회" 또는 "찾Go" 로고를 누릅니다. | 물품 목록을 보여줍니다. 없는 주소로 들어와도 물품 목록으로 안내합니다. 불러오는 동안 "불러오는 중..."을 표시합니다. | - |
| 2 | 목록을 훑어봅니다. | 등록 일시(createdAt) 최신순으로 카드를 20개씩 보여줍니다. 카드에는 사진(없으면 기본 이미지), 분실물/습득물 표시, 이름, 장소, 날짜(분실·습득 날짜)가 있습니다. 더 보려면 맨 아래 "더 보기"를 누릅니다. | - |
| 3 | 검색어를 입력하고 구분(전체/분실물/습득물)과 상태(전체/찾는 중/해결 완료)를 고른 뒤 "검색"을 누릅니다. | 이름, 설명, 장소, 보관 장소 중 하나에 검색어가 들어 있고 조건에 맞는 물품만 보여줍니다. | - |
| 4 | 찾는 물건과 비슷한 카드를 누릅니다. | 상세 화면에서 구분, 이름, 사진(없으면 기본 이미지), 특징·설명, 장소, 날짜, 보관 장소(습득물만), 작성자 이름, 작성자 연락처(로그인한 사용자만)를 보여줍니다. 값이 없는 칸은 보여주지 않습니다. 비회원에게는 연락처 자리에 "로그인하면 작성자 연락처를 볼 수 있습니다."를 보여줍니다. | - |
| 5 | 내 물건이 아니면 "← 목록으로"를 누릅니다. | 검색 조건이 그대로 남은 목록으로 돌아갑니다. | - |

**종료 상태:** 상세 화면의 **보관 장소**(예: 학생부실, 행정실)에 가서 물건을 받거나, 로그인한 뒤 **작성자 연락처**로 연락합니다. 물건을 받는 과정은 2-6에 정리합니다.

### 2-2. 회원가입

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 헤더의 "로그인"을 누르거나, 로그인이 필요한 기능을 누릅니다. | 로그인 화면을 보여줍니다. | - |
| 2 | "아직 계정이 없으신가요? 회원가입"을 누릅니다. | 회원가입 화면을 보여줍니다. | - |
| 3 | 이메일, 이름, 비밀번호, 비밀번호 확인을 입력합니다. 원하면 전화번호도 입력합니다. | 비어 있는 필수 칸, 잘못된 이메일 형식, 일치하지 않는 비밀번호, 잘못된 전화번호 형식을 해당 칸 아래에 알려줍니다. | 필수 네 칸 모두 올바르게 입력. 전화번호는 입력했다면 010-0000-0000 형식 |
| 4 | "회원가입"을 누릅니다. | 버튼을 "가입 중..."으로 바꾸고 다시 누를 수 없게 합니다. | 가입 성공 |
| 5 | - | "회원가입이 완료되었습니다. 로그인해주세요." 안내 후, 이메일이 채워진 로그인 화면으로 이동합니다. | - |

**종료 상태:** 가입 완료 안내를 보고, 내 이메일이 채워진 로그인 화면에서 비밀번호만 입력하면 됩니다.

### 2-3. 로그인

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 이메일과 비밀번호를 입력하고 "로그인"을 누릅니다. | 비어 있는 칸이 있으면 해당 칸을 알려줍니다. 버튼을 "로그인 중..."으로 바꾸고 다시 누를 수 없게 합니다. | 두 칸 모두 입력 |
| 2 | - | 서버가 발급한 토큰(accessToken)과 사용자 정보를 브라우저에 저장합니다. 원래 하려던 화면(예: 물품 등록)으로 이동하고, 헤더의 "로그인"을 눌러 직접 들어왔다면 마이페이지로 이동합니다. | 로그인 성공 |
| 3 | 화면 위쪽 헤더를 확인합니다. | "로그인"이 "OOO님"으로 바뀌고 "로그아웃" 버튼이 생깁니다. | - |

**종료 상태:** 헤더에 "OOO님"이 보이고, 하려던 화면 또는 마이페이지가 열립니다.

이미 로그인한 사용자가 로그인·회원가입 화면에 들어오면 입력 칸 대신 "이미 로그인되어 있습니다." 안내와 "마이페이지로 가기" 버튼을 보여줍니다.

### 2-4. 물품 등록

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | 목록 화면에서 "습득물 등록하기" 또는 "분실물 등록하기"를 누릅니다. | 등록 화면을 열고, 누른 버튼에 맞게 구분(습득물/분실물)을 미리 선택해 둡니다. | 로그인 상태. 아니면 "로그인이 필요한 기능입니다." 안내와 함께 로그인 화면으로 이동하고, 로그인 후 등록 화면으로 돌아옵니다. |
| 2 | 구분 \*, 분실물/습득물 명 \*, 특징·상세 설명 \*, 장소 \*, 날짜 \*, 보관 장소 \*(습득물만)를 입력합니다. | 필수 항목에는 \* 표시를 하고, 칸마다 입력 예시를 보여줍니다. 날짜는 오늘로 미리 채워 둡니다. 보관 장소 칸은 습득물일 때만 보여주고 반드시 입력받습니다. 구분을 분실물로 바꾸면 칸을 숨기고 값을 비웁니다. | - |
| 3 | 사진을 끌어 놓거나 "파일에서 선택하기"를 누릅니다. (선택) | 고른 사진의 미리보기를 보여줍니다. 사진은 한 장만 올릴 수 있고, 이미지 주소 직접 입력은 받지 않습니다. | JPG/PNG, 5MB 이하 사진 |
| 4 | "등록하기"를 누릅니다. | 비어 있는 필수 항목이 있으면 그 칸을 알려주고 등록하지 않습니다. 모두 입력했으면 버튼을 "등록 중..."으로 바꿉니다. | 필수 항목 모두 입력 (습득물은 보관 장소 포함) |
| 5 | - | 방금 등록한 물품의 상세 화면으로 이동합니다. | 등록 성공 |

**종료 상태:** 등록한 물품의 상세 화면이 열리고 "수정"·"삭제" 버튼이 보입니다. 마이페이지의 "내가 등록한 물품" 목록과 "등록한 습득물/분실물" 개수에도 반영됩니다.

### 2-5. 내 물품 수정·삭제

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |

### 2-6. 물건 돌려받기와 해결 완료

소유 확인과 물건 전달은 서비스 밖에서 사람이 직접 합니다. 보관 장소에서 하거나, 작성자 연락처로 연락해서 합니다. 서비스는 그 뒤에 작성자가 바꾼 '해결 완료' 상태만 저장합니다.

| # | 사용자 행동 | 서비스 반응 | 다음 조건 |
| --- | --- | --- | --- |
| 1 | (분실자) 상세 화면에서 보관 장소와 작성자 연락처를 확인합니다. | 로그인한 사용자에게는 작성자 연락처를 보여줍니다. 작성자가 전화번호를 입력하지 않았으면 연락처 칸을 보여주지 않습니다. 비회원에게는 연락처 자리에 "로그인하면 작성자 연락처를 볼 수 있습니다."를 보여줍니다. | - |
| 2 | (분실자) 보관 장소에 가서 물건의 특징을 말하거나, 작성자에게 연락해 특징을 확인받습니다. | - (서비스 밖) | 소유 확인 |
| 3 | 보관 장소에서 받아 가거나, 작성자와 약속해서 받습니다. | - (서비스 밖) | 물건 전달 |
| 4 | (작성자) 마이페이지 → 내 물품 상세 → "수정"에서 상태를 "해결 완료"로 바꾸고 "수정하기"를 누릅니다. | 버튼을 "수정 중..."으로 바꿉니다. 저장되면 상세 화면에 "해결 완료"를 보여주고, 목록에서도 해결 완료로 구분해 보여줍니다. | 작성자 본인, 저장 성공 |

- 습득물 게시물의 작성자는 습득자입니다. 물건을 보관 장소에 맡겨 두었다면, 보관 장소에서 반환됐는지 확인한 뒤 해결 완료로 바꿉니다.
- 분실물 게시물의 작성자는 분실자입니다. 물건을 되찾으면 직접 해결 완료로 바꿉니다.
- 같은 물건에 분실물 글과 습득물 글이 따로 있어도 서비스는 두 글을 연결하지 않습니다. 물건이 돌아간 뒤 두 글의 작성자가 각자 해결 완료로 바꿉니다.

**종료 상태:** 목록과 상세 화면에 "해결 완료"가 보여, 다른 학생이 이미 주인을 찾은 물건임을 알 수 있습니다.

### 3-2. 공통 원칙

"오류가 생겨도 사용자가 현재 위치와 다음 행동을 알 수 있어야 합니다"를 지키기 위해 모든 화면에 다음 원칙을 적용합니다.

1. **헤더는 항상 보입니다.** 어느 화면에서든 로고와 "습득/분실물 조회"로 목록(첫 화면)에, "OOO님"으로 마이페이지에 돌아갈 수 있습니다.
2. **안내 문구에는 다음 행동을 함께 적습니다.** "실패했습니다"로 끝내지 않고 "다시 시도해주세요", "다른 검색어로 찾아보세요"처럼 할 일을 알려줍니다.
3. **오류·빈 결과 화면에는 돌아갈 버튼을 둡니다.** "목록으로", "다시 시도", "물품 등록하기"처럼 다음 행동으로 바로 가는 버튼을 함께 보여줍니다.
4. **실패해도 입력한 내용은 지우지 않습니다.** 사용자가 처음부터 다시 입력하지 않도록 합니다.
5. **로그인으로 보낼 때는 이유를 알리고, 로그인 후 원래 화면으로 돌려보냅니다.**
6. **처리 중에는 버튼 문구를 "~ 중..."으로 바꾸고 다시 누를 수 없게 합니다.** 같은 요청이 두 번 가지 않도록 합니다.
