## 2. 우선순위 결정하기

| 분류 | 판단 기준 | 해당 기능 | 판단 근거 |
| --- | --- | --- | --- |
| 첫 버전 필수 | 빠지면 핵심 목적을 달성할 수 없는 기능 | • 회원가입 및 로그인/로그아웃 • 물품 등록 • 물품 목록 조회 • 물품 검색 • 마이페이지 • 물품 관리 | 회원가입과 로그인으로 작성자를 구분하고, 물품 등록으로 게시물을 올립니다. 등록된 게시물은 분류하고 정렬해 편하게 조회할 수 있고, 검색으로 분실물을 더 빠르게 찾을 수 있습니다. 상태 변경으로 물품을 효율적으로 관리하며, 마이페이지에서 내 게시물을 확인하고 수정·삭제할 수 있습니다. 이러한 과정을 통해 사용자가 편하고 효율적으로 분실물을 찾을 수 있습니다. |
| 후속 개선 | 핵심 흐름은 가능하지만 편의성과 완성도를 높이는 기능 | 채팅, 유사도 분석, 물품 종류 선택·필터 | 첫 버전에서는 습득물 게시물에 적힌 보관 장소로 찾아가거나 작성자 연락처로 연락해 물건을 돌려받을 수 있습니다. 하지만 채팅이 있으면 연락처를 공개하지 않고도 주인 확인과 전달이 쉬워지고, 유사도 분석이 있으면 직접 검색하지 않아도 비슷한 물품을 찾을 수 있어 더 효율적으로 분실물을 관리할 수 있습니다. 물품 종류는 검색어로도 찾을 수 있어 첫 버전에서 뺐습니다. |
| 범위 제외 | 현재 목표와 직접 연결되지 않거나 근거가 부족한 기능 | 모바일 앱, 푸시 알림 | 모바일 웹으로도 핵심 흐름을 모두 쓸 수 있기 때문에 사용자가 늘어난 뒤 필요성을 다시 판단할 수 있습니다. |

## 3. 기능별 동작 정리하기

### 1. 회원가입

- **시작 조건**: 로그인하지 않은 사용자가 로그인 화면에서 회원가입 버튼을 누른다
- **처리 과정**: 입력 형식(이메일, 비밀번호(8~64자), 비밀번호 확인, 이름 - 필수 / 전화번호 - 선택)과 이메일 중복을 확인한 뒤 회원 정보를 저장한다
- **결과**: 가입이 완료되고 이메일이 채워진 로그인 화면으로 이동한다.
- **실패 시 처리**
  - 미입력: "이름을 입력해 주세요."
  - 이메일 중복 : "이미 가입된 이메일입니다. 로그인해주세요."
  - 비밀번호 확인 불일치: "비밀번호가 일치하지 않습니다."
  - 전화번호 형식 오류: "전화번호 형식을 확인해 주세요."

### 2. 로그인 / 로그아웃

- **시작 조건**: 상단 메뉴에서 로그인 또는 로그아웃 버튼을 누르거나, 로그인하지 않은 상태에서 로그인이 필요한 기능(등록·마이페이지)을 누른다
- **처리 과정**: 입력한 이메일과 비밀번호가 회원 정보와 맞으면 서버가 JWT 토큰(accessToken)을 발급하고, 화면은 토큰과 사용자 정보를 저장한다. 로그아웃하면 서버에 요청하지 않고 저장된 토큰과 사용자 정보를 삭제한다
- **결과**: 로그인 상태가 유지되고 원래 하려던 화면으로 이동한다(없으면 마이페이지). 이제 물품 등록과 관리 기능을 쓸 수 있다. 로그아웃하면 물품 목록(첫 화면)으로 이동한다
- **실패 시 처리**
  - 정보 불일치: "이메일 또는 비밀번호가 올바르지 않습니다. 다시 입력해주세요."

### 3. 물품 등록

- **시작 조건**: 로그인한 사용자가 물품 목록(첫 화면)의 등록 버튼을 누른다. 로그인하지 않았으면 로그인 화면을 거쳐 등록 화면으로 돌아온다
- **처리 과정**: 사진을 먼저 업로드한다(선택). 물품 이름, 설명, 장소, 날짜는 필수로 입력한다. 보관 장소는 습득물일 때 필수이며, 분실물 등록 화면에는 입력 칸을 표시하지 않는다. 칸 표시는 프론트엔드가, 습득물의 필수 검사는 프론트엔드와 백엔드가 함께 한다. 작성자는 로그인한 사용자로 지정한다
- **결과**: 게시물이 저장되고 등록한 물품의 상세 화면으로 이동한다
- **실패 시 처리**
  - 미입력: "이름·설명·장소·날짜(습득물은 보관 장소까지) 입력은 필수입니다."
  - 글자 수 초과: "이름·장소는 100자, 설명은 2000자 이하로 입력하세요."
  - 사진 용량 초과: "사진은 5MB 이하로 올려 주세요."
  - 사진 형식 오류: "JPG 또는 PNG 사진을 업로드해 주세요."
  - 로그인 안 됨: "로그인이 필요한 기능입니다."

### 4. 물품 목록 조회

- **시작 조건**: 사용자가 서비스에 접속하면 처음 보이는 화면이다. 상단 메뉴에서도 들어갈 수 있다 (로그인 불필요)
- **처리 과정**: 등록된 물품을 분실물과 습득물로 나누고, 등록 일시(createdAt) 최신순으로 20개씩 보여 준다. "더 보기"로 다음 20개를 이어 붙인다. 분실·습득 날짜(lostFoundAt)는 표시만 하고 정렬에 쓰지 않는다. 해결 완료된 물품은 표시로 구분하고, 미해결 물품만 보려면 상태 필터를 쓴다
- **결과**: 분류별로 정리된 물품 목록이 표시된다
- **실패 시 처리**
  - 결과 없음 : "아직 등록된 물품이 없습니다. 첫 물품을 등록해 보세요."

### 5. 물품 상세 조회

- **시작 조건**: 목록이나 검색 결과에서 물품을 선택한다
- **처리 과정**: 선택한 물품의 정보를 불러온다
- **결과**: 사진(없으면 기본 이미지), 이름, 설명, 장소, 보관 장소(습득물만), 날짜, 상태, 작성자 이름, 작성자 연락처(로그인한 사용자만)가 표시된다. 값이 없는 선택 항목은 칸을 표시하지 않는다. 사용자는 내 물건인지 확인하고 보관 장소로 찾아가거나 작성자에게 연락한다. 본인 물건임을 확인받고 돌려받는 과정은 서비스 밖에서 이루어진다
- **실패 시 처리**
  - 조회 실패: "물품을 찾을 수 없습니다."
  - 비회원: 연락처 자리에 "로그인하면 작성자 연락처를 볼 수 있습니다."

### 6. 물품 검색

- **시작 조건**: 목록 화면 상단의 검색창에 검색어를 입력하거나 조건을 고른다 (로그인 불필요)
- **처리 과정**: 물품 이름, 설명, 장소, 보관 장소에서 검색어를 찾는다. 유형(분실물/습득물), 상태(찾는 중/해결 완료), 정렬(최신순/오래된 순, 등록 일시 기준) 조건을 함께 적용한다
- **결과**: 조건에 맞는 물품이 20개씩 표시된다
- **실패 시 처리**
  - 검색어 초과: "검색어는 100자 이하로 입력하세요."
  - 결과 없음: "조건에 맞는 물품이 없어요"

### 7. 마이페이지

- **시작 조건**: 로그인한 사용자가 상단 메뉴의 마이페이지에 들어간다
- **처리 과정**: 로그인한 사용자가 등록한 물품만 불러온다. 전체로 보거나 유형·상태별로 분류해서 볼 수 있다
- **결과**: 내 물품 목록이 표시되고, 각 물품에서 수정·삭제·상태 변경으로 이동할 수 있다
- **실패 시 처리**
  - 로그인 안 됨: "로그인이 필요합니다."
  - 등록한 물품 없음: "아직 등록한 물품이 없어요"

### 8. 물품 관리 (수정·삭제·상태 변경)

- **시작 조건**: 작성자가 마이페이지나 상세 화면에서 수정, 삭제, 상태 변경 버튼을 누른다
- **처리 과정**
  - 수정: 입력한 내용으로 게시물 정보를 바꾼다
  - 삭제: 게시물을 지운다
  - 상태 변경: 물건이 주인에게 전달된 뒤, 작성자가 수정 화면에서 상태를 '찾는 중' 또는 '해결 완료'로 바꿔 저장한다. 소유 확인과 물건 전달은 서비스 밖(보관 장소, 또는 작성자와 연락)에서 이루어지고, 서비스는 상태 값만 저장한다. 같은 물건의 분실물 글과 습득물 글은 연결하지 않으므로 각 작성자가 따로 바꾼다
- **결과**: 바뀐 내용이 목록과 상세 화면에 바로 반영된다. 해결 완료된 물품은 목록에서 구분되어 보인다
- **실패 시 처리**
  - 작성자가 아님: "본인이 등록한 물품만 변경할 수 있습니다."
  - 로그인 안 됨: "로그인이 필요합니다."
  - 수정 시 입력 오류: 물품 등록과 같은 메시지
