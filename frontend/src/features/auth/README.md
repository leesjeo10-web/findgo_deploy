# 인증 구조안

[최신 결정](../../../docs/decisions.md)과 [전체 구조](../../../docs/frontend-structure.md)를 따른다.
학생 아이디 6자리·관리자 admin, 회원가입 없음, JWT, 서비스 화면 전체 로그인 필요가 현재 기획이다.

- LoginPage / LoginForm: loginId·password 입력, 계정 문의·오류·만료 안내. 로그인은 빈 칸만 검사하므로 admin을 숫자 규칙으로 막지 않는다.
- 추가 예정 PasswordChangePage / PasswordChangeForm: 첫 로그인 강제 변경과 마이페이지의 일반 변경. 현재 비밀번호·새 비밀번호·확인 입력을 공유한다.
- RequireAuth: 인증 확인 중·로그인 없음·mustChangePassword 상태를 구분. 변경 화면 자체는 허용해 무한 이동을 막는다.
- 추가 예정 RequireAdmin: ADMIN 역할 확인. 학생 관리 페이지를 보호한다.
- api/: 로그인·내 정보 조회·비밀번호 변경 계약.
- model/: 인증 상태·역할·비밀번호 변경 필요 여부·검증 규칙.

로그인 성공은 변경 필요 시 변경 화면, 그 외 목록으로 이동한다. 이전 주소 복귀는 없다.
비밀번호 변경은 204 응답이므로 내 정보를 다시 조회해 변경 필요 여부를 갱신하는 방식을 제안한다.
비밀번호·확인 값은 폼 안에서만 취급한다. 회원가입 뼈대는 보관만 하고 새 라우트·API에서 제외한다.
5회 실패·10분 잠금·현재 비밀번호 재사용 금지는 디자인에만 있는 추가 정책이며 아직 확정하지 않는다.
현재 JSX·라우터·API는 구현하지 않았다.
