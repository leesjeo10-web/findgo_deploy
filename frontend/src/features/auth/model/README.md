# 인증 상태 자리

구현 단계에서 로그인 사용자·인증 확인 상태·role·mustChangePassword를 관리한다.
초기에는 GET /api/auth/me로 확인하고, 확인 중에 보호된 내용을 먼저 보여주지 않는다.
로그인 후 이전 주소 복귀는 하지 않는다. 변경 필요면 변경 화면, 그 밖에는 물품 목록으로 이동한다.

로그아웃·만료 때 토큰과 이전 사용자의 정보·연락처·조회 데이터를 정리한다.
최신 예외 문서는 만료 때 작성 중인 물품 폼을 보관하지 않는다고 정한다.
비밀번호는 전역 상태나 브라우저 저장소에 보관하지 않는다.
저장 위치·토큰 수명·만료 처리의 실제 구현은 백엔드 계약과 확인 후 진행한다.
현재 상태 저장소 구현은 없다.
